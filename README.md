## Featured Project

### QuizAI - AI Quiz Generator

QuizAI turns a topic into a multiple-choice quiz that learners can answer and review. It generates 5, 8, or 10 questions at beginner, intermediate, or advanced difficulty using the Groq API and GPT-OSS 120B.

- Builds structured question data and checks that each question has four answer choices and a matching correct answer.
- Calculates the quiz score and shows correct answers with explanations.
- Deployed as a Streamlit web application.

**Technologies:** Python, Streamlit, Groq API, GPT-OSS 120B, JSON

**Live demo:** [Try QuizAI](https://quizai-jxi7os8aetywa8tqtzsgf8.streamlit.app/)
